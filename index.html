01 — What I do

i.

Build the platform

I run AWS and Kubernetes platforms defined as code, from networking and identity up to the cluster: CloudFormation at work, Terraform in my own projects. Changes come from a reviewed template, not from clicks in a console.

  • cloudformation
  • terraform
  • eks
  • vpc
  • iam

ii.

Ship it safely

I build pipelines that release several times a week without drama: tested, scanned, staged and reversible. GitOps keeps the cluster in step with what is in Git.

I automated Kustomize-based deployments on EKS, including environment-specific blue-green overlays.

Keep it running, automate the rest

I instrument services so problems surface early and recovery is fast. Then I automate the repeat work around them, including AI-assisted review.
